# Adopt Engineering Field Notes Visual System

The portfolio will migrate its visual system toward **Engineering Field Notes**, based on the FinTrack lineage HTML draft's paper-toned technical memo style. The decision favors a full-page **Document Canvas** over decorative cards, **Light-First Paper** over automatic dark mode, sans-first **Engineering Memo Typography**, **Wide Canvas, Readable Prose**, and **Rule-Based Separation** for page hierarchy.

Tags, dates, section labels, and technical labels should read as **Metadata Text**, not UI chips. Bordered or shaded surfaces are reserved for **Semantic Content Blocks** such as code blocks, callouts, tables, diagrams, and figures. Colored technology icons may be tried as an **Icon Color Trial**, but only if they remain compact metadata marks and do not turn the page into a logo cloud.

The migration should happen in two stages: first establish the visual foundation across global tokens, body typography, navigation, layout width, and base content elements; then convert individual pages away from cards, pills, and old Tailwind gray/dark styling into rule-based document layouts.
